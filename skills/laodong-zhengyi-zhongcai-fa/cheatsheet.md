# 速查表

## 数字阈值

| 事项 | 数字 | 条文 |
|---|---|---|
| 仲裁申请时效期间 | 1年 | 第27条 |
| 时效起算点 | 知道或应当知道权利被侵害之日 | 第27条 |
| 劳动者一方推举代表门槛 | 十人以上且有共同请求 | 第7条 |
| 调解组织收到申请后未达成协议可转仲裁 | 十五日 | 第14条 |
| 仲裁委收到仲裁申请后受理/不予受理决定 | 五日 | 第29条 |
| 受理后送达申请书副本给被申请人 | 五日 | 第30条 |
| 被申请人提交答辩书 | 收到副本后十日 | 第30条 |
| 通知仲裁庭组成情况 | 受理之日起五日 | 第32条 |
| 开庭通知 | 开庭五日前书面通知 | 第35条 |
| 请求延期开庭 | 开庭三日前 | 第35条 |
| 仲裁裁决期限 | 受理之日起四十五日 | 第43条 |
| 裁决延期上限 | 十五日 | 第43条 |
| 终局裁决金额上限 | 不超过当地月最低工资标准十二个月金额 | 第47条 |
| 劳动者不服终局裁决起诉期限 | 收到裁决书之日起十五日 | 第48条 |
| 用人单位申请撤销终局裁决期限 | 收到裁决书之日起三十日 | 第49条 |
| 裁决被撤销后起诉期限 | 收到裁定书之日起十五日 | 第49条 |
| 不服非终局裁决起诉期限 | 收到裁决书之日起十五日 | 第50条 |
| 劳动争议仲裁收费 | 不收费 | 第53条 |
| 本法施行日期 | 2008年5月1日 | 第54条 |
