# 劳动争议全流程（laodong-liucheng）

## 技能定位

本 skill 按时间顺序列出劳动争议六个阶段——协商、调解、仲裁、一审、二审、执行——每个阶段的**期限、材料、证据、风险点**。期限类数字全部回源核实，有条文出处；**二审与执行为重点阶段**（使用者多处于此阶段）。

**阶段关系**：协商→调解→仲裁→一审→二审→执行，依次递进。注意：**劳动争议仲裁是诉讼的前置程序**（《中华人民共和国劳动争议调解仲裁法》第5条：发生劳动争议，当事人不愿协商、协商不成或达成和解协议后不履行的，可以向调解组织申请调解；不愿调解、调解不成或达成调解协议后不履行的，可以向劳动争议仲裁委员会申请仲裁；对仲裁裁决不服的，可以向人民法院提起诉讼）——未经仲裁直接起诉，法院不受理。
