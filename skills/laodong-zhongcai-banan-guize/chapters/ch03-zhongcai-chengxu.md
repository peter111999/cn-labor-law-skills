# 第三章 仲裁程序（第26–67条）

## 第一节 申请和受理（第26–36条）

- **第26条**：本规则第2条第(一)、(三)、(四)、(五)项规定的争议，申请仲裁的时效期间为一年，自当事人知道或者应当知道其权利被侵害之日起计算；第2条第(二)项规定的争议（聘任制公务员等）适用公务员法有关规定；劳动人事关系存续期间因拖欠劳动报酬发生争议的，劳动者申请仲裁不受一年时效限制，但劳动人事关系终止的，应当自终止之日起一年内提出
- **第27条**：仲裁时效中断——在时效期间内有下列情形之一的，从中断时起重新计算：(一)一方通过协商、申请调解等方式向对方主张权利；(二)一方向有关部门投诉、向仲裁委员会申请仲裁、向人民法院起诉或者申请支付令等方式请求权利救济；(三)对方当事人同意履行义务
- **第28条**：仲裁时效中止——因不可抗力，或者无/限制民事行为能力劳动者的法定代理人未确定等正当理由不能申请仲裁的，从中止时效的原因消除之日起继续计算
- **第29条**：申请人申请仲裁应当提交书面仲裁申请，并按被申请人人数提交副本；申请书载明劳动者姓名、性别、出生日期、身份证件号码、住所、通讯地址和联系电话，用人单位名称、住所、通讯地址、联系电话和法定代表人/主要负责人姓名职务，仲裁请求和事实理由，证据和证据来源、证人姓名住所；书写困难可口头申请记入笔录经确认；申请书不规范或材料不齐备的，当场或在五日内一次性告知补正全部材料；收取材料出具收件回执
- **第30条**：受理条件（四项）：(一)属于第2条规定的争议范围；(二)有明确的仲裁请求和事实理由；(三)申请人是与本案有直接利害关系的自然人、法人或其他组织，有明确的被申请人；(四)属于本仲裁委员会管辖范围；符合的在收到仲裁申请之日起五日内出具受理通知书
- **第31条**：不符合第30条第(一)(二)(三)项之一的不予受理，5日内出具不予受理通知书；不符合第(四)项（管辖）的，5日内书面说明并告知向有管辖权的仲裁委员会申请；逾期未作出决定或决定不予受理的，申请人可就该争议事项向人民法院提起诉讼
- **第32条**：受理后发现不应当受理的（第9条移送情形除外），应当撤销案件，并自决定撤销案件后五日内以决定书形式通知当事人
- **第33条**：受理后5日内将仲裁申请书副本送达被申请人；被申请人收到副本后10日内提交答辩书；收到答辩书后5日内将副本送达申请人；逾期未提交答辩书不影响程序进行
- **第34条**：下列情形申请人基于同一事实、理由和仲裁请求又申请仲裁的不予受理：(一)已依法出具不予受理通知书；(二)案件已在仲裁、诉讼过程中或者调解书、裁决书、判决书已发生法律效力
- **第35条**：仲裁处理结果作出前申请人可自行撤回仲裁申请；再次申请仲裁的应当受理
- **第36条**：被申请人可在答辩期间提出反申请，仲裁委员会自收到反申请之日起五日内决定是否受理并通知；决定受理的可合并处理；应另行申请仲裁的书面告知另行申请；不属于应当受理的出具不予受理通知书；答辩期满后提出反申请的应当另行申请仲裁

## 第二节 开庭和裁决（第37–55条）

- **第37条**：仲裁委员会应当在受理仲裁申请之日起五日内组成仲裁庭并将组成情况书面通知当事人
- **第38条**：仲裁庭应当在开庭五日前将开庭日期、地点书面通知双方当事人；有正当理由的可在开庭三日前请求延期开庭，是否延期由仲裁委员会决定
- **第39条**：申请人无正当理由拒不到庭或未经同意中途退庭的，按撤回仲裁申请处理，重新申请仲裁的不予受理；被申请人无正当理由拒不到庭或中途退庭的，可缺席裁决
- **第40条**：当事人申请鉴定的，鉴定费由申请鉴定方先行垫付，案件处理终结后由鉴定结果对其不利方负担；鉴定结果不明确的由申请鉴定方负担
- **第41条**：开庭程序——记录人员查明到庭、宣布仲裁庭纪律；仲裁员宣布开庭、案由和人员名单，核对当事人，告知权利义务，询问是否申请回避；听取陈述和答辩，主持庭审调查、质证和辩论，征询最后意见，并进行调解
- **第42条**：开庭情况记入笔录；当事人认为记录有遗漏差错可当庭申请补正；仲裁员、记录人员、当事人等应在庭审笔录上签名或盖章，拒绝的记明附卷
- **第43条**：仲裁庭纪律——不得未经准许录音录像摄影、未经准许以移动通信等方式现场传播庭审、其他扰乱秩序妨害审理的行为；违者可训诫、责令退出、暂扣器材责令删除内容，拒不删除可强制删除并记入笔录
- **第44条**：申请人在举证期限届满前可增加或变更仲裁请求，审查认为应受理的通知被申请人并给予答辩期（明确放弃除外）；届满后提出应另行申请仲裁
- **第45条**：仲裁庭裁决案件应当自受理仲裁申请之日起四十五日内结束；案情复杂需延期的，经仲裁委员会主任或其委托的仲裁院负责人书面批准可延期并书面通知当事人，延长期限不得超过十五日
- **第46条**：仲裁期限计算的七种情形：(一)追加当事人或第三人从决定追加之日起重新计算；(二)申请人补正材料从补正之日起重新计算收到申请时间；(三)增加、变更仲裁请求从受理增变请求之日起重新计算；(四)申请和反申请合并处理从受理反申请之日起重新计算；(五)移送管辖从接受移送之日起重新计算；(六)中止审理期间、公告送达期间不计入；(七)法律法规规定另行计算的其他情形
- **第47条**：中止审理的七种情形（经主任/仲裁院负责人批准并书面通知）：(一)劳动者一方死亡需等继承人表明是否参加；(二)劳动者一方丧失民事行为能力尚未确定法定代理人；(三)用人单位终止尚未确定权利义务承继者；(四)一方因不可抗拒事由不能参加仲裁；(五)需以其他案件审理结果为依据且他案未审结；(六)需等工伤认定、伤残等级鉴定及其他鉴定结论；(七)其他应当中止的情形；情形消除后恢复审理
- **第48条**：因仲裁庭逾期未裁决当事人向人民法院起诉并立案受理的，仲裁委员会决定终止审理；未就该争议事项起诉的继续处理
- **第49条**：一部分事实已清楚的可先行裁决；不服先行裁决按调解仲裁法有关规定处理
- **第50条**：终局裁决适用——追索劳动报酬、工伤医疗费、经济补偿或赔偿金，单项裁决数额不超过当地月最低工资标准十二个月金额的事项适用终局裁决（经济补偿包括劳动合同法规定的竞业限制期限内经济补偿、解除或终止劳动合同的经济补偿等；赔偿金包括未签订书面劳动合同第二倍工资、违法约定试用期赔偿金、违法解除或终止劳动合同赔偿金等）；因执行国家劳动标准在工作时间、休息休假、社会保险等方面发生的争议适用终局裁决；同时涉及终局和非终局裁决的分别制作裁决书并告知救济权利
- **第51条**：先予执行——追索劳动报酬、工伤医疗费、经济补偿或赔偿金的案件依当事人申请可裁决先予执行，移送人民法院执行；条件：(一)权利义务关系明确；(二)不先予执行将严重影响申请人生活；劳动者申请可不提供担保
- **第52条**：裁决按多数仲裁员意见作出，少数意见记入笔录；不能形成多数意见时按首席仲裁员意见作出
- **第53条**：裁决书载明仲裁请求、争议事实、裁决理由、裁决结果、当事人权利和裁决日期；由仲裁员签名，加盖仲裁委员会印章；持不同意见的仲裁员可签名也可不签名
- **第54条**：裁决书文字、计算错误或已裁决但遗漏的事项，应及时制作决定书补正并送达当事人
- **第55条**：不服裁决向人民法院起诉按调解仲裁法有关规定处理

## 第三节 简易处理（第56–61条）

- **第56条**：可简易处理的三种情形：(一)事实清楚、权利义务关系明确、争议不大；(二)标的额不超过本省、自治区、直辖市上年度职工年平均工资；(三)双方当事人同意简易处理；可指定一名仲裁员独任仲裁并告知当事人
- **第57条**：不得简易处理的四种情形：(一)涉及国家利益、社会公共利益；(二)有重大社会影响；(三)被申请人下落不明；(四)仲裁委员会认为不宜简易处理
- **第58条**：经与被申请人协商同意，仲裁庭可缩短或取消答辩期
- **第59条**：可用电话、短信、传真、电子邮件等简便方式送达仲裁文书（调解书、裁决书除外）；未经当事人确认或无其他证据证明已收到的开庭通知，不得按撤回申请处理或缺席裁决
- **第60条**：可根据案件情况确定举证期限、开庭日期、审理程序、文书制作等事项，但应保障当事人陈述意见的权利
- **第61条**：发现不宜简易处理的，应在仲裁期限届满前决定转一般程序并告知当事人；期限自受理仲裁申请之日起计算；双方已确认的事实可不再举证质证

## 第四节 集体劳动人事争议处理（第62–67条）

- **第62条**：劳动者一方在十人以上并有共同请求的争议案件，或因履行集体合同发生的劳动争议案件适用本节；符合第56条第一款情形之一的集体案件可简易处理，不受本节限制
- **第63条**：十人以上的劳动者可推举三至五名代表参加仲裁活动；代表人行为对被代表当事人发生效力，但变更、放弃仲裁请求或承认对方仲裁请求、进行和解须经被代表当事人同意；履行集体合同争议协商不成工会可依法申请仲裁，尚未建立工会的由上级工会指导推举代表申请
- **第64条**：自收到集体争议仲裁申请之日起五日内作出受理或不予受理决定；决定受理的自受理之日起五日内将仲裁庭组成人员、答辩期限、举证期限、开庭日期和地点一次性通知当事人
- **第65条**：集体争议案件由三名仲裁员组成仲裁庭，设首席仲裁员；履行集体合同争议按三方原则组成仲裁庭
- **第66条**：开庭前引导自行协商或先行调解；可邀请法律工作者、律师、专家学者等第三方共同参与调解；协商或调解未达成协议的及时裁决
- **第67条**：开庭场所可设在发生争议的用人单位或其他便于及时处理争议的地点

## 数字与阈值
- 仲裁时效：1年（第26条；"十五日"指自然日，第80条）
- 补正告知：当场或5日内一次性告知（第29条）
- 受理/不予受理决定：收到申请之日起5日内（第30、31条）
- 撤销案件通知：决定后5日内（第32条）
- 送达申请书副本：受理后5日内；答辩期限：10日内；送达答辩书副本：5日内（第33条；"五日""十日"指工作日，第80条）
- 反申请受理决定：收到之日起5日内（第36条）
- 组成仲裁庭：受理之日起5日内（第37条）
- 开庭通知：开庭5日前；延期申请：开庭3日前（第38条）
- 裁决期限：受理之日起45日内，可延期15日（第45条）
- 终局裁决线：单项不超过当地月最低工资标准12个月金额（第50条）
- 简易处理标的线：不超过本省上年度职工年平均工资（第56条）
- 集体争议受理决定：收到申请之日起5日内（第64条）
