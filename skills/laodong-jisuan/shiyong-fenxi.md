# 适用分析：2N / N+1 / N 决策路径（shiyong-fenxi.md）

> 使用流程：先问清三个事实——①谁提出解除 ②解除是否符合法定情形和程序 ③解除前12个月工资构成。再套用以下路径。事实不清时先提问，不猜测结论。

## 决策树

```
谁提出解除？
├─ 用人单位提出
│   ├─ 违法解除（不符合第39/40/41条条件或程序，或违反第42条）
│   │   → 2N（《中华人民共和国劳动合同法》第87条）
│   │     劳动者另有选择权：要求继续履行（第48条）
│   ├─ 符合第40条三种情形＋程序合法
│   │   → N + 1（或提前30天通知代替+1）（第40条、第46条）
│   ├─ 符合第39条（过失性辞退）
│   │   → 无 N（第46条未列入）
│   ├─ 符合第41条第1款（经济性裁员）
│   │   → N（第46条）
│   └─ 协商一致（用人单位提出）
│       → N（第46条）
├─ 劳动者提出
│   ├─ 依第38条被迫解除（未及时足额付酬、未缴社保等）
│   │   → N（第46条）；注意收集"被迫"的证据
│   ├─ 提前30天通知辞职（第37条）
│   │   → 无 N
│   └─ 协商一致（劳动者提出）
│       → 无 N（第46条只覆盖"用人单位提出"的协商一致）
└─ 合同终止（期满、退休、单位解散等，第44条）
    ├─ 除单位维持/提高条件续订而劳动者不同意外，固定期限届满终止 → N
    ├─ 第44条第4、5项（单位破产/吊销等）终止 → N
    └─ 劳动者开始依法享受基本养老保险待遇 → 无 N
```

## 互斥规则（重要）

| 组合 | 能否并存 | 依据/逻辑 |
|---|---|---|
| 2N + N | ❌ 否 | 2N 已按"经济补偿标准的二倍"计算，再加 N 属重复。违法解除的法律后果是"继续履行 or 2N"（《中华人民共和国劳动合同法》第48条、第87条） |
| 2N + 1 | ❌ 否 | +1 是第40条合法解除的程序选项；2N 是违法解除的责任。同一解除行为要么合法要么违法 |
| N + 1 | ✅ 可以 | 第40条合法解除：N（第46条）与 +1（第40条）并存 |
| 2N + 二倍工资 | ✅ 可以 | 不同性质：违法解除责任 vs 未签合同惩罚 |
| N + 二倍工资 | ✅ 可以 | 同上 |
| 继续履行 + 2N | ❌ 否 | 二选一（《中华人民共和国劳动合同法》第48条） |

互斥规则中"❌否"的部分系条文逻辑推导（非法条逐字原文），回答时应说明这是法律逻辑而非逐字条文。

## 实务请求策略（非法条原文，属策略提示，须标注）

- 违法解除争议：主请求 2N，备位请求 N（"如仲裁庭不认定违法解除，请求支付经济补偿 N"），由仲裁庭择一支持
- 被迫解除（第38条）：请求 N；同时可主张欠付工资、加班费等
- 注意仲裁时效 1 年（《中华人民共和国劳动争议调解仲裁法》第27条）
