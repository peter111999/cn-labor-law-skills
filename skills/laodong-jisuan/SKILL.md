# 劳动补偿计算（laodong-jisuan）

## 技能定位

本 skill 解决"该赔多少、怎么算"的问题：给出计算公式、基数确定方法、封顶上限，并根据使用者提供的事实判断适用 N、N+1 还是 2N。条文依据全部回源核实，公式中的每一个数字阈值均有出处。

**本 skill 不代替个案法律意见**：计算依赖使用者的事实输入（工资构成、工作年限、解除方式等），输入不准则结果不准；地方口径不一致处必须按 `difang-chayi.md` 单独提示使用者咨询当地仲裁委或律师。

## 适用情形

- "被公司辞退，能拿多少补偿" → `formulas/f01-jingji-buchang-N.md` + `shiyong-fenxi.md`
- "N+1 是怎么算的" → `formulas/f02-daitongzhi-jin.md`
- "公司违法解除，我要 2N" → `formulas/f03-peichangjin-2N.md` + `shiyong-fenxi.md`
- "没签劳动合同的双倍工资" → `formulas/f04-erbei-gongzi.md`
- "加班费 150%/200%/300% 怎么算" → `formulas/f05-jiaban-gongzi.md`
- "工伤十级能赔多少" → `formulas/f06-gongshang-daiyu.md`
- "我这种情况适用 2N 还是 N+1" → `shiyong-fenxi.md`（先问清解除方式、谁提出的解除、是否违法）

## 不触发情况

- 问社保缴费基数、社保补缴 → shebao-fa skill
- 问工伤认定（算不算工伤）→ gongshangbaoxian-tiaoli skill（本 skill 只算"认定为工伤之后"的待遇金额）
- 问仲裁/诉讼程序、时效 → laodong-zhengyi-zhongcai-fa / minshi-susong-fa skill
- 问个人所得税具体税率 → 本 skill 不覆盖税法，只说明经济补偿基数用税前应得工资
