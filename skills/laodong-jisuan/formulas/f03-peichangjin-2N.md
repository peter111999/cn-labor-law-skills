# 违法解除赔偿金 2N（formulas/f03）

## 适用条件

用人单位**违反《中华人民共和国劳动合同法》规定**解除或终止劳动合同（《中华人民共和国劳动合同法》第87条）。

典型情形：不符合第39条（过失性辞退）、第40条（无过失性辞退）、第41条（经济性裁员）等法定条件和程序而解除；或在第42条禁止解除的情形下解除。

## 公式

**2N = 工作年限（年）× 月工资 × 2**

即按《中华人民共和国劳动合同法》第47条经济补偿标准的**二倍**支付赔偿金。工作年限折算、月工资基数、封顶规则与 N 完全相同（见 f01）。

## 劳动者的选择权

《中华人民共和国劳动合同法》第48条：用人单位违法解除或终止，劳动者**要求继续履行的，应当继续履行**；劳动者**不要求继续履行或者劳动合同已经不能继续履行的**，用人单位按第87条支付赔偿金。

即：**继续履行** 与 **2N 赔偿金** 二选一，不能既要回去上班又要 2N。

## 2N 与 N、N+1 的互斥关系

- **2N 与 N 不能并存**：2N 是违法解除的法定责任，其计算"标准"是经济补偿标准的二倍，不存在"2N 再加 N"。主张违法解除赔偿金，就不再主张经济补偿（条文逻辑：《中华人民共和国劳动合同法》第87条、第48条；司法实践亦如此）
- **2N 与 N+1 不能并存**：+1 适用于第40条**合法**解除的三种情形；2N 适用于**违法**解除。同一解除行为要么合法要么违法，不存在既违法又符合第40条的情形
- 实务建议（非法条原文，属策略提示）：仲裁请求中可将 2N 作为主请求、N 作为备位请求，由仲裁庭根据是否认定违法解除来择一支持；不要在同一请求中把两者相加

## 易错点

- 2N 的"2"乘的是 N 的全套标准（含封顶规则），不是简单翻倍实发工资
- 违法解除的举证：因用人单位作出的解除劳动合同决定发生的争议，用人单位负举证责任（《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》第44条）
- 注意仲裁时效：劳动争议申请仲裁的时效期间为 1 年（《中华人民共和国劳动争议调解仲裁法》第27条，见 laodong-zhengyi-zhongcai-fa skill），从知道或应当知道权利被侵害之日起算
