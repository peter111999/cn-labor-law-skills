# 劳动争议典型案例库术语表

> 定义出自案例原文或已有 skill；仅收录本库案例中出现的术语。

| 术语 | 含义（出自原文） |
|---|---|
| 典型案例 | 人社部、最高法联合筛选发布的案例；通知原文表述为"请各地仲裁机构、人民法院在办案中**予以参照**"，不等于指导案例的"应当参照" |
| 混同用工 | 关联企业之间对劳动者混同用工，人为造成劳动关系归属模糊并在诉讼中相互推诿（最高法2025案例二典型意义原文） |
| 人格从属性 | 平台企业的工作规则、劳动纪律、奖惩办法是否适用于劳动者，能否通过制定规则、设定算法对劳动过程进行管理控制；劳动者是否须按平台指令完成任务、能否自主决定工作时间工作量（第三批案例1案例分析原文） |
| 经济从属性 | 平台企业是否掌握劳动者从业必需的数据信息等重要生产资料、是否允许劳动者商定服务价格；劳动者通过平台获得的报酬是否构成其重要收入来源（第三批案例1案例分析原文） |
| 组织从属性 | 劳动者是否被纳入平台企业组织体系、成为生产经营组织的有机部分，并以平台名义对外提供服务（第三批案例1案例分析原文） |
| 事实优先原则 | 认定劳动关系应当根据用工事实，不因书面约定为"合作关系"而否定（第三批案例1案例分析原文） |
| 不完全符合确立劳动关系的情形 | 人社部发〔2021〕56号《指导意见》明确的介于劳动关系与民事关系之间的情形（第三批案例2原文援引） |
| 停工留薪期 | 工伤职工暂停工作接受工伤医疗、原工资福利待遇不变的期限；一般不超过12个月，经设区的市级劳动能力鉴定委员会确认可延长，但延长不得超过12个月（《工伤保险条例》第33条，第四批案例1原文援引） |
| 竞业限制适格主体 | 限于用人单位的高级管理人员、高级技术人员和其他负有保密义务的人员（《劳动合同法》第24条，第四批案例5原文援引） |
| 在职竞业限制 | 用人单位与竞业限制人员以书面协议约定在职期间负有竞业限制义务（最高法2025案例五典型意义原文） |
| 用工主体责任 | 不具备合法经营资格的组织或个人招用的劳动者，转包分包的承包人、被挂靠单位承担支付劳动报酬、工伤保险待遇等责任（《司法解释二》第1、2条；最高法2025案例一） |
| 二倍工资 | 用人单位自用工之日起超过一个月不满一年未与劳动者订立书面劳动合同，向劳动者每月支付二倍的工资（《劳动合同法》第82条，最高法2025案例三典型意义原文） |
| "三期"女职工 | 孕期、产期、哺乳期女职工（第四批案例2典型意义原文） |
| 包薪制 | 在劳动合同中打包约定法定标准工作时间工资和加班费的一种工资分配方式（第二批案例4典型意义原文） |
| 特别仲裁时效 | 劳动关系存续期间因拖欠劳动报酬发生争议，仲裁时效不受"知道或应当知道权利被侵害之日起一年"的限制；劳动关系终止的，应当自终止之日起一年内提出（《调解仲裁法》第27条，第二批案例10案例分析原文） |
