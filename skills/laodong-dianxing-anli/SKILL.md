# 劳动争议典型案例库

> ⚠️ 性质声明（必读）：本库收录的是**典型案例**，不是最高人民法院**指导案例**。
> 指导案例的规范表述是"应当参照"；典型案例的规范表述是"**予以参照**"（第三批、第四批通知原文），
> 两者效力不同。第一批（最高法2025年8月1日发布）正文无参照效力表述，如实记录。
> 第二批（加班费争议）原为图片扫描版经OCR提取，2026-09-26先用人社部官网单篇页面校准（存疑标注清零，每案附单篇URL与发布日期），再以最高人民法院官网全量页面（2021-08-26发布）逐字比对并修正4处文字/标点差异；
> 第二批页面本身即案例正文发布，未见独立通知原文及文号；未见"予以参照"/"应当参照"等参照效力表述，如实记录。
> 个案结论不能直接套用于其他案件，具体适用须结合案情。

|---|---|
| 没签合同，能要双倍工资吗／公司不跟我签合同 | 最高法2025案例三（冉某：劳动者故意不订立则用人单位不负二倍工资责任） |
| 公司让我签竞业限制协议／竞业限制有效吗 | 最高法2025案例四（郑某：义务范围须与知悉商业秘密相适应）；第四批案例5（保安李某：主体不适格则条款无效） |
| 在职期间自己接单做同类业务 | 最高法2025案例五（黄某：在职竞业限制有效，违约担责） |
| 公司不给交社保／让我签不交社保的协议 | 最高法2025案例六（朱某：约定无效，可解除并要经济补偿）；第四批案例4（李某：自行承担的可向单位索赔） |
| 外卖骑手／网约车司机／网约配送员，算劳动关系吗 | 第三批案例1–6（新就业形态劳动关系认定） |

| 停工留薪期想延长／医院开了休假证明 | 第四批案例1（彭某：延长须经劳动能力鉴定委员会确认，诊断证明书不足） |
| 几个关联公司混着用我，劳动关系算谁的 | 最高法2025案例二（王某：混同用工可按主张结合案情认定） |
| 怀孕了公司调岗降薪 | 第四批案例2（赵某：不得因怀孕调岗降薪） |
| 家人病亡，社保断缴过 | 第四批案例3（刘某松遗属：可要抚恤金差额） |
| 拒绝违法超时加班被公司解除 | 第二批案例1（张某：规章制度违法则无效，拒绝加班不属不符合录用条件） |
| 入职时签了放弃加班费的协议，还能要加班费吗 | 第二批案例2（张某：放弃加班费协议无效） |
| 公司说没走加班审批流程，不认我的加班 | 第二批案例3（吴某：审批手续不影响"用人单位安排"加班的认定） |
| 工资是包薪制，含加班费，还能要差额吗 | 第二批案例4（周某：包薪制也须足额支付加班费） |
| 公司突然加工作量，变相让我加班，能拒绝吗 | 第二批案例5（张某：大幅增加工作任务属变相强迫加班，有权拒绝） |
| 加班费官司，谁来举证 | 第二批案例6（林某：谁主张谁举证+用人单位掌握证据不提供承担不利后果） |
| 超时加班出工伤，劳务派遣两家公司谁赔 | 第二批案例7（李某工亡：用工单位与派遣单位连带赔偿） |
| 离职时签了"加班费已结清"，还能再要吗 | 第二批案例9（肖某：非真实意思表示的确认无效，二审改判支持） |
| 加班费的仲裁时效怎么算 | 第二批案例10（张某：加班费适用拖欠劳动报酬特别仲裁时效） |
