# 术语表（均出自原文）

- **诉讼参加人**：当事人和诉讼代理人以外的参与诉讼活动的人的总称（本法中使用于第52条、第65条等）。
- **诉讼标的**：当事人之间争议的民事权利义务关系（第55–57条、第59条）。
- **共同诉讼**：当事人一方或双方为二人以上，诉讼标的共同，或诉讼标的同一种类、法院认为可合并审理并经当事人同意的诉讼（第55条）。
- **代表人诉讼**：当事人一方人数众多的共同诉讼，由当事人推选代表人进行诉讼（第56–57条）。
- **第三人**：对当事人双方的诉讼标的有独立请求权，或虽无独立请求权但案件处理结果同他有法律上利害关系的人（第59条）。
- **诉讼代理人**：当事人、法定代理人委托的一至二人代为诉讼的人（第61条）。
- **特别授权**：诉讼代理人代为承认、放弃、变更诉讼请求，进行和解，提起反诉或上诉，须有委托人的特别授权（第62条）。
- **回避**：审判人员等有法定情形时退出本案审理的制度（第47–50条）。
- **合议庭**：由审判员、人民陪审员共同组成或由审判员组成的审理组织，成员人数须为单数（第40–41条）。
- **独任审理**：由审判员一人审理案件（第40条、第163条）。
- **人民陪审员**：参加审判活动、除法律另有规定外与审判员有同等权利义务的人员（第40条）。
- **两审终审**：第二审法院的判决、裁定是终审的判决、裁定（第10条、第182条）。
- **一审终审**：小额诉讼程序（第165条）、特别程序（第185条）实行一审终审。
- **举证责任**：当事人对自己提出的主张有责任提供证据（第67条）。
- **举证期限**：法院根据当事人的主张和案件审理情况确定的当事人提供证据的期限（第68条）。
- **质证**：证据在法庭上出示并由当事人互相质证（第71条）。
- **鉴定**：当事人就专门性问题申请、由具备资格的鉴定人进行的专业判断（第79–81条）。
- **勘验**：勘验人对物证或现场的查验并制作笔录（第83条）。
- **证据保全**：证据可能灭失或以后难以取得时，法院采取的保全措施（第84条）。
- **期间**：法定期间和法院指定的期间（第85条）。
- **送达**：法院将诉讼文书送交受送达人的程序（第87–95条）。
- **留置送达**：受送达人拒绝接收时，把文书留在其住所并记录送达过程即视为送达（第89条）。
- **电子送达**：经受送达人同意，采用能确认其收悉的电子方式送达（第90条）。
- **公告送达**：受送达人下落不明或用其他方式无法送达时公告送达，自发出公告之日起经过30日即视为送达（第95条）。
- **调解书**：调解达成协议后法院制作的文书，经双方签收后具法律效力（第100条）。
- **保全**：法院对可能因一方行为或其他原因使判决难以执行或造成当事人其他损害的案件，裁定对财产保全、责令作出或禁止作出一定行为（第103–108条）。
- **先予执行**：法院对追索赡养费等、追索劳动报酬、情况紧急需先予执行的案件，根据当事人申请裁定先予执行（第109–110条）。
- **拘传**：对必须到庭的被告经两次传票传唤无正当理由拒不到庭时采取的强制到庭措施（第112条）。
- **罚款 / 拘留**：对妨害民事诉讼行为的强制措施；个人罚款10万元以下、单位5万–100万元、拘留15日以下（第114条、第118条）。
- **诉讼费用**：当事人进行民事诉讼按规定交纳的案件受理费及其他诉讼费用（第121条）。
- **级别管辖 / 地域管辖 / 专属管辖 / 协议管辖 / 移送管辖 / 指定管辖**：确定案件由哪一级、哪一地法院审理的规则（第18–39条）。
- **管辖权异议**：当事人对管辖权有异议时在提交答辩状期间提出的异议（第130条）。
- **反诉**：被告对原告提出的独立的反请求（第54条、第143条）。
- **缺席判决**：被告经传票传唤无正当理由拒不到庭或未经许可中途退庭时作出的判决（第147条）。
- **发回重审**：二审法院裁定撤销原判决、发回原审法院重审（第177条）。
- **提审**：上级法院对下级法院已生效裁判发现确有错误时直接提审（第209条）。
- **再审**：对已生效的判决、裁定、调解书确有错误时重新审理（第209–218条）。
- **抗诉**：检察院对已生效裁判发现法定情形时提出的抗诉（第219条）。
- **检察建议**：地方各级检察院对同级法院已生效裁判可提出的检察建议（第219–220条）。
- **支付令**：债权人请求给付金钱、有价证券符合条件时法院发出的督促债务人履行的命令（第225–228条）。
- **督促程序**：依支付令申请审理的程序（第十七章）。
- **公示催告**：票据被盗、遗失或灭失时向票据支付地基层法院申请的程序（第229–234条）。
- **执行**：生效法律文书确定的义务由法院强制实现（第三编）。
- **申请执行时效**：申请执行的期间为2年（第250条）。
- **执行异议**：当事人、利害关系人认为执行行为违反法律规定提出的书面异议（第236条）。
- **案外人异议**：执行中案外人对执行标的提出的书面异议（第238条）。
- **执行回转**：据以执行的法律文书被撤销后，对已执行财产责令返还（第244条）。
- **迟延履行金 / 迟延履行期间的债务利息**：被执行人未按指定期间履行义务时应加倍支付的利息或支付的迟延履行金（第264条）。
- **司法协助**：法院与外国法院相互请求代为送达、调查取证等（第293–296条）。
- **承认和执行**：外国法院生效判决、裁定及外国仲裁裁决经审查后承认效力并执行（第297–304条）。
- **外国国家豁免**：涉及外国国家的民事诉讼适用我国有关外国国家豁免的法律规定（第305条）。
