## 适用情形

用户出现以下说法时，优先调用本技能（条文号均已回源核实；劳动纠纷场景优先）：

- "不服仲裁裁决去法院起诉""公司告我了/我要起诉公司" → 第122条起诉四条件、第127条（有书面仲裁协议不得起诉的告知仲裁）、第18条（基层法院管辖一审）、第22条（被告住所地）、第24条（合同纠纷被告住所地/合同履行地）。注：劳动仲裁裁决不服的15日起诉期限见《劳动争议调解仲裁法》第50条，属另一技能范围，此处仅标注。
- "一审怎么开庭""开庭流程" → 第十二章（第122–127条起诉受理、第128–136条审理前准备、第137–151条开庭审理、第152条普通程序6个月审限、第155–159条判决裁定）

- "判决错了想再审""申请再审" → 第十六章（第210条向上一级/原审法院申请；第211条十三项再审情形；第216条：生效后6个月，211条第1/3/12/13项自知道起6个月；第215条审查3个月；第213条解除婚姻关系的判决调解书不得再审）

## 不触发情况

以下情形不调用本技能：

- 仅讨论法律新闻、热点案件，不涉及具体法条适用
- 仅询问法律考试、备考、法学理论问题
- 仅要求推荐律师、律所等法律服务
- 用户明确表示不需要引用法条、只要通俗建议
- **仲裁阶段问题**（申请劳动仲裁、仲裁开庭、仲裁时效、仲裁裁决效力）→ 用 `laodong-zhengyi-zhongcai-fa` / `laodong-zhongcai-banan-guize` 技能
- **实体权利问题**（经济补偿/赔偿金计算、加班工资标准、工伤认定、社保缴纳）→ 用 `laodong-hetong-fa` / `laodongfa` / `gongshangbaoxian-tiaoli` / `shebao-fa` 技能
- 劳动仲裁裁决不服的起诉期限（15日）→ 《劳动争议调解仲裁法》第50条，属 `laodong-zhengyi-zhongcai-fa` 技能范围；本技能仅提供起诉条件（第122条）与管辖（第二章）
