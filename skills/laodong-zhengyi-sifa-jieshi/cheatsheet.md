# 关键条文速查（全部回源核实，带条文号）

## 数字阈值

| 内容 | 阈值 | 条文 |
|---|---|---|
| 竞业限制经济补偿（未约定补偿时） | 解除/终止前12个月平均工资的30%，按月支付；低于履行地最低工资标准的，按最低工资标准 | 第36条 |
| 单位原因3个月未付竞业补偿 | 劳动者可请求解除竞业限制约定 | 第38条 |
| 单位解除竞业限制协议 | 额外支付劳动者3个月竞业限制经济补偿 | 第39条 |
| 终局裁决金额线 | 每项数额均不超过当地月最低工资标准12个月金额 | 第19条 |
| 用人单位申请撤销终局裁决期限 | 自收到不予受理裁定书之日起30日内，向仲裁机构所在地中院申请 | 第18条 |
| 劳动者撤诉/被驳回起诉后，单位申请撤销期限 | 自收到裁定书之日起30日内 | 第21条 |
| 不予执行裁定后起诉期限 | 收到裁定书之次日起30日内 | 第24条 |
| 财产保全后申请执行期限 | 裁决书/裁判文书生效后3个月内；逾期不申请，裁定解除保全 | 第49条 |
| 口头变更劳动合同实际履行期限 | 超过1个月，且内容合法、不违背公序良俗，不得以未书面为由主张无效 | 第43条 |

## 高频指引

| 问题 | 答案要点 | 条文 |
|---|---|---|
| 拿着工资欠条能直接去法院吗 | 可以，不涉及劳动关系其他争议的，按普通民事纠纷受理 | 第15条 |
| 仲裁超期没出结果怎么办 | 可直接向法院起诉（6种除外情形），需提交受理通知书等凭证 | 第12条 |
| 对仲裁裁决部分不服 | 起诉后整个仲裁裁决不发生法律效力 | 第16条 |
| 被公司逼着辞职 | 5种迫使解除情形，单位应付劳动报酬+经济补偿，并可付赔偿金 | 第45条 |
| 换单位工龄能否连续算 | 非因本人原因被安排到新单位，原单位未付补偿的，5种情形可合并计算 | 第46条 |
| 加班费谁举证 | 劳动者先举证加班事实；单位掌握证据不提供的，单位承担不利后果 | 第42条 |
| 单位开除/降薪谁举证 | 用人单位负举证责任 | 第44条 |
| 解除协议签了能反悔吗 | 无欺诈胁迫乘人之危、不违反强制性规定→有效；重大误解/显失公平→可撤销 | 第35条 |
| 退休返聘算劳动关系吗 | 已享受养老保险待遇/领取退休金的，按劳务关系处理 | 第32条 |
| 申请支付令 | 依劳动合同法30条2款、调解仲裁法16条，符合督促程序的法院应受理 | 第13条 |
| 公司规章制度有效吗 | 民主程序制定、不违法、已公示的，可作确定权利义务依据；与合同不一致，劳动者可请求优先适用合同 | 第50条 |
| 调解协议有法律效力吗 | 调解组织主持下具劳动权利义务内容的，有劳动合同约束力，可作裁判根据 | 第51条 |
