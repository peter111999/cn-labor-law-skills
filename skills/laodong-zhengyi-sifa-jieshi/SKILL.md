## 适用情形

用户出现以下说法时，优先调用本技能（条文号均已回源核实）：
- "仲裁后起诉""对仲裁裁决不服怎么办" → 第16条（部分不服则裁决不生效）、第4条（双方均起诉则并案审理）、第18条（终局/非终局分别处理）
- "社保问题法院管不管" → 第1条第5项（未办社保手续且不能补办致无法享受待遇、索赔损失→法院受理）、第2条第1项（请求社保经办机构发放社保金→不属劳动争议）
- "竞业限制补偿""想解除竞业限制" → 第36–40条
- "加班费谁举证""单位开除我谁举证" → 第42条、第44条
- "被公司逼着辞职" → 第45条（5种迫使解除情形）
- "换单位工龄能不能连续算" → 第46条（5种合并计算情形）
- "拿着工资欠条能直接起诉吗" → 第15条（按普通民事纠纷受理）
- "什么是终局裁决" → 第19条（每项不超过当地月最低工资12个月金额）
- "想撤销仲裁裁决" → 第21–23条
- "仲裁超期没裁决" → 第12条
- "申请支付令" → 第13条
- "退休后被返聘算劳动关系吗" → 第32条（按劳务关系处理）
- "解除协议反悔/显失公平" → 第35条

## 不触发情况

以下情形不调用本技能：
- 仅讨论法律新闻、热点案件，不涉及具体条文适用
- 仅询问法律考试、备考、法学理论问题
- 仅要求推荐律师、律所等法律服务
- 用户明确表示不需要引用条文、只要通俗建议
- 问题仅涉及实体权利义务标准（如经济补偿如何计算、加班工资倍数）且不涉及仲裁诉讼程序，优先使用劳动合同法/劳动法技能
