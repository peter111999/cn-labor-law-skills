# 术语表（定义均出自《劳动人事争议仲裁组织规则》原文）

| 术语 | 定义（原文依据） |
|---|---|
| 争议 | 劳动人事争议的简称（第1条） |
| 仲裁委员会 | 由人民政府依法设立，专门处理争议案件的劳动人事争议仲裁委员会（第2条） |
| 仲裁院 | 仲裁委员会下设的实体化办事机构，称为劳动人事争议仲裁院，设在人力资源社会保障行政部门（第9条） |
| 仲裁庭 | 仲裁委员会处理争议案件实行仲裁庭制度，实行一案一庭制（第12条） |
| 一案一庭制 | 仲裁委员会处理争议案件实行仲裁庭制度，一个案件设立一个仲裁庭（第12条） |
| 首席仲裁员 | 三名仲裁员组成的仲裁庭设首席仲裁员（第13条） |
| 独任仲裁 | 简单争议案件可以由一名仲裁员独任仲裁（第13条） |
| 专职仲裁员 | 由仲裁委员会聘任的专职从事调解仲裁工作的仲裁员，与兼职仲裁员享有同等权利、履行同等义务（第18条） |
| 兼职仲裁员 | 由仲裁委员会从相关机构人员、专家学者、律师中聘任的非专职仲裁员（第18、19条） |
| 记录人员 | 负责案件庭审记录等相关工作的人员，不得由本庭仲裁员兼任（第14条） |
| 办案辅助人员 | 如记录人员、安保人员等，可通过政府购买服务方式聘用（第10条、第35条） |
| 聘前培训 | 人力资源社会保障行政部门对拟聘任的仲裁员进行的培训（第27条） |
| 仲裁监督 | 仲裁委员会建立的对申请受理、办案程序、处理结果、仲裁工作人员行为进行监督的制度（第32条） |
