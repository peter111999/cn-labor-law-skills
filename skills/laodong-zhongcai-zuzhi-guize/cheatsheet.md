# 数字阈值速查（全部回原文核实，括号内为条文号）

## 数字阈值
- 仲裁委员会组成人员：**单数**（第5条）
- 全体会议：每年**至少2次**（第8条）
- 提议召开会议：主任或**三分之一以上**组成人员（第8条）
- 三人仲裁庭情形之一：**十人以上**并有共同请求的争议（第13条）
- 专职仲裁员：**不得少于3名**；办案辅助人员：**不得少于1名**（第22条）
- 仲裁员聘期：一般**5年**（第24条）
- 仲裁员年度脱产培训：累计**不少于40学时**（第28条）
- 仲裁员禁止行为：**9项**（第33条）
- 解聘后禁聘期：**5年内**不得再次被聘（第34条）
- 本规则施行：**2017年7月1日**；旧规则（人社部令第5号）**同时废止**（第38条）

## 高频指引
- 仲裁委员会由谁决定设立 → 省、自治区、直辖市人民政府（第4条）
- 仲裁委员会主任由谁担任 → 政府负责人或人社行政部门主要负责人（第6条）
- 仲裁委员会六项职责 → 聘任解聘仲裁员、受理案件、讨论重大疑难案件、监督仲裁活动、制定工作规则（第7条）
- 简单案件 → 可独任仲裁（第13条）
- 记录人员能否由本庭仲裁员兼任 → 不得（第14条）
- 仲裁员选聘条件 → 符合调解仲裁法第二十条（第22条，援引）
- 聘前培训分级 → 省级/副省级市由人社部组织，地市县区由省级人社部门组织（第27条）
- 仲裁员证/徽章 → 人社部统一免费发放；解聘辞职后收回并公告（第36、37条）
