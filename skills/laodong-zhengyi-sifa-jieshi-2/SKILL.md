## 适用情形

用户出现以下说法时，优先调用本技能（条文号均已回源核实）：
- "包工头没资质，工资找谁要""挂靠公司出了工伤找谁" → 第1–2条（承包人/被挂靠单位承担用工主体责任）
- "被几个关联公司来回用工，劳动关系算谁的" → 第3条（混同用工：有书面合同按合同，无合同综合认定）
- "公司没签合同，二倍工资怎么算""我自己不肯签合同还能要二倍工资吗" → 第6条（按月算，不满一月按实际工作日）、第7条（三项例外）
- "合同到期公司一直拖着不续签" → 第11条（超过一个月可请求以原条件续订）
- "怎么算连续订立二次固定期限劳动合同" → 第10条（四种认定情形）
- "公司给了落户/住房让我签服务期，提前走要赔吗" → 第12条（损失赔偿规则，非违约金）
- "没接触过公司机密，竞业限制协议有效吗""竞业限制范围太大" → 第13条（不生效/超过合理比例部分无效）
- "在职期间的竞业限制有效吗" → 第14条（有效，未付补偿不得主张无效）
- "违反竞业限制要赔多少" → 第15条（返还已付经济补偿+支付违约金）
- "公司违法解除，什么情况下算不能继续履行" → 第16条（六种情形）
- "没做离岗体检就解除合同" → 第17条
- "公司说好不交社保多发钱" → 第19条（约定无效；可依劳动合同法38条解约并要经济补偿）
- "仲裁时没提时效，一审还能提吗" → 第20条
- "解释二和解释一冲突" → 第21条（以解释二为准；解释一第32条第1款废止）
