# 术语表

本表只收录《劳动合同法实施条例》原文中出现的术语，解释以原文文义为准，不引申。

| 术语 | 出处 | 说明（出自原文） |
|---|---|---|
| 劳动合同法 | 第1条 | 指《中华人民共和国劳动合同法》，本条例为贯彻实施该法而制定 |
| 用人单位 | 第3条、第4条 | 包括依法成立的会计师事务所、律师事务所等合伙组织和基金会；其依法设立并取得营业执照或登记证书的分支机构可作为用人单位订立劳动合同 |
| 用工之日 | 第5–7条 | 劳动关系建立、双倍工资起算的基准日；"自用工之日起一个月内""超过一个月不满一年""满一年" |
| 两倍的工资 | 第6条、第7条、第34条 | 用人单位未订立书面劳动合同，依照劳动合同法第八十二条向劳动者每月支付的工资 |
| 职工名册 | 第8条 | 应当包括劳动者姓名、性别、公民身份号码、户籍地址及现住址、联系方式、用工形式、用工起始时间、劳动合同期限等内容 |
| 无固定期限劳动合同 | 第7条、第11条、第12条 | 满一年未订立书面劳动合同视为已订立；符合劳动合同法第十四条第二款条件的，劳动者提出则用人单位应当订立 |
| 公益性岗位 | 第12条 | 地方各级人民政府及县级以上地方人民政府有关部门为安置就业困难人员提供的给予岗位补贴和社会保险补贴的岗位 |
| 服务期 | 第16条、第17条、第26条 | 用人单位与劳动者依照劳动合同法第二十二条约定的服务期限；服务期未满而合同期满的，劳动合同续延至服务期满 |
| 培训费用 | 第16条 | 包括用人单位为对劳动者进行专业技术培训而支付的有凭证的培训费用、培训期间的差旅费用以及因培训产生的用于该劳动者的其他直接费用 |
| 额外支付劳动者一个月工资 | 第20条 | 用人单位依照劳动合同法第四十条选择额外支付一个月工资解除劳动合同（即"代通知金"）；按劳动者上一个月的工资标准确定 |
| 经济补偿 | 第22条、第25条、第27条、第31条 | 月工资按劳动者应得工资计算，包括计时工资或计件工资以及奖金、津贴和补贴等货币性收入 |
| 赔偿金 | 第25条、第34条 | 用人单位违反劳动合同法规定解除或终止劳动合同，依照劳动合同法第八十七条支付；支付了赔偿金不再支付经济补偿；计算年限自用工之日起计算 |
| 劳务派遣单位 | 第28条、第30–32条 | 用人单位或其所属单位出资或合伙设立、向本单位或所属单位派遣劳动者的，属于劳动合同法第六十七条规定的不得设立的劳务派遣单位 |
| 用工单位 | 第29条、第35条 | 接受被派遣劳动者、应当履行劳动合同法第六十二条义务的单位 |
| 被派遣劳动者 | 第29–32条、第35条 | 由劳务派遣单位派遣到用工单位工作的劳动者 |
| 劳动行政部门 | 第33–36条 | 负责责令改正、罚款、处理投诉举报的行政机关（县级以上地方人民政府劳动行政部门） |
| 连带赔偿责任 | 第35条 | 用工单位违反劳务派遣规定给被派遣劳动者造成损害的，劳务派遣单位和用工单位承担连带赔偿责任 |
