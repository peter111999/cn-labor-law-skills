# 中华人民共和国劳动合同法实施条例

## 如何使用

- **不带参数** — 浏览下面的立法目的与章节索引
- **带主题** — 问"双倍工资""连续工龄""劳务派遣"等，我定位相关条文并引用条文号作答

## 适用情形

用户出现以下说法时，优先调用本技能：
- "公司没和我签劳动合同，能要双倍工资吗""双倍工资从哪天算到哪天" → 第二章（第6条、第7条）
- "换了公司/被调到新单位，工龄怎么算""之前的工作年限还算吗" → 第二章（第10条）
- "干满十年能不能要求签无固定期限合同" → 第二章（第9条、第11条）
- "试用期工资能打几折" → 第二章（第15条）
- "公司让我签服务期/培训协议，违约金怎么算" → 第二章（第16条、第17条）、第三章（第26条）
- "N+1的+1按什么标准算" → 第三章（第20条）
- "经济补偿的月工资包括奖金吗""不满12个月怎么算" → 第三章（第27条）
- "被违法解除，赔偿金和经济补偿能都要吗" → 第三章（第25条）
- "劳务派遣有什么限制" → 第四章（第28–32条）
- "退休了劳动合同还有效吗" → 第三章（第21条）
- "工伤职工被终止合同有什么待遇" → 第三章（第23条）

## 不触发情况

以下情形不调用本技能：
- 仅讨论法律新闻、热点案件，不涉及具体法条适用
- 仅询问法律考试、备考、法学理论问题
- 仅要求推荐律师、律所等法律服务
- 用户明确表示不需要引用法条、只要通俗建议
- 劳动合同权利义务的基础问题（如解除条件、经济补偿年限）→ 优先《劳动合同法》技能（laodong-hetong-fa），本条例是其配套细则
