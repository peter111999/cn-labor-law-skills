# 第五章 工伤保险待遇（第30–45条）

## 本章要点
- **第30条**：职工因工作遭受事故伤害或患职业病治疗，享受工伤医疗待遇；应在签订服务协议的医疗机构就医，紧急时可先到就近医疗机构急救；治疗费用符合工伤保险诊疗项目目录、药品目录、住院服务标准的，从工伤保险基金支付；住院伙食补助费及经证明报经办机构同意到统筹地区以外就医的交通、食宿费用，从基金支付（具体标准由统筹地区人民政府规定）；治疗非工伤引发疾病不享受工伤医疗待遇，按基本医疗保险处理
- **第31条**：认定为工伤的决定作出后发生行政复议、行政诉讼的，期间不停止支付工伤医疗费用
- **第32条**：工伤职工因日常生活或就业需要，经劳动能力鉴定委员会确认，可安装假肢、矫形器、假眼、假牙和配置轮椅等辅助器具，费用按国家规定标准从基金支付
- **第33条**：停工留薪期内原工资福利待遇不变，由所在单位按月支付；停工留薪期一般不超过12个月，伤情严重或情况特殊经设区的市级劳动能力鉴定委员会确认可延长，但延长不得超过12个月；评定伤残等级后停发原待遇，按有关规定享受伤残待遇；停工留薪期满后仍需治疗的继续享受工伤医疗待遇；生活不能自理的工伤职工在停工留薪期需要护理的，由所在单位负责
- **第34条**：评定伤残等级并经确认需要生活护理的，从基金按月支付生活护理费；标准分别为统筹地区上年度职工月平均工资的50%（完全不能自理）、40%（大部分不能自理）、30%（部分不能自理）
- **第35条**：一级至四级伤残：保留劳动关系，退出工作岗位。(一)一次性伤残补助金：一级27个月、二级25个月、三级23个月、四级21个月的本人工资；(二)按月伤残津贴：一级本人工资90%、二级85%、三级80%、四级75%，低于当地最低工资标准的由基金补足差额；(三)达到退休年龄办理退休后停发伤残津贴，按国家规定享受基本养老保险待遇，低于伤残津贴的由基金补足差额。用人单位和职工个人以伤残津贴为基数缴纳基本医疗保险费
- **第36条**：五级、六级伤残：(一)一次性伤残补助金：五级18个月、六级16个月的本人工资；(二)保留劳动关系，由用人单位安排适当工作，难以安排的由用人单位按月发伤残津贴（五级本人工资70%、六级60%），并缴纳各项社会保险费，低于当地最低工资标准的由用人单位补足差额。经职工本人提出可解除或终止劳动关系，由基金支付一次性工伤医疗补助金、用人单位支付一次性伤残就业补助金，具体标准由省、自治区、直辖市人民政府规定
- **第37条**：七级至十级伤残：(一)一次性伤残补助金：七级13个月、八级11个月、九级9个月、十级7个月的本人工资；(二)劳动、聘用合同期满终止或职工本人提出解除合同的，由基金支付一次性工伤医疗补助金、用人单位支付一次性伤残就业补助金，具体标准由省、自治区、直辖市人民政府规定
- **第38条**：工伤复发确认需要治疗的，享受第30条、第32条和第33条规定的工伤待遇
- **第39条**：职工因工死亡，近亲属从基金领取：(一)丧葬补助金为6个月的统筹地区上年度职工月平均工资；(二)供养亲属抚恤金：按职工本人工资一定比例发给生前提供主要生活来源、无劳动能力的亲属，配偶每月40%、其他亲属每人每月30%、孤寡老人或孤儿每人每月在上述标准上增加10%，核定总和不应高于死亡职工生前工资，供养亲属范围由国务院社会保险行政部门规定；(三)一次性工亡补助金标准为上一年度全国城镇居民人均可支配收入的20倍。停工留薪期内因工伤死亡的，近亲属享受本条第一款全部待遇；一至四级伤残职工停工留薪期满后死亡的，近亲属可享受第(一)(二)项待遇
- **第40条**：伤残津贴、供养亲属抚恤金、生活护理费由统筹地区社会保险行政部门根据职工平均工资和生活费用变化等情况适时调整，办法由省级政府规定
- **第41条**：职工因工外出期间发生事故或在抢险救灾中下落不明的，从事故发生当月起3个月内照发工资，从第4个月起停发工资，由基金向其供养亲属按月支付抚恤金；生活困难的可预支一次性工亡补助金的50%；被人民法院宣告死亡的，按第39条处理
- **第42条**：停止享受工伤保险待遇的3种情形：(一)丧失享受待遇条件的；(二)拒不接受劳动能力鉴定的；(三)拒绝治疗的
- **第43条**：用人单位分立、合并、转让的，承继单位承担原单位的工伤保险责任；承包经营的由职工劳动关系所在单位承担；借调期间由原用人单位承担（可约定补偿办法）；企业破产的在清算时依法拨付应由单位支付的工伤保险待遇费用
- **第44条**：职工被派遣出境工作，依前往国家或地区法律应参加当地工伤保险的参加当地保险、国内关系中止；不能参加的国内关系不中止
- **第45条**：职工再次发生工伤应享受伤残津贴的，按新认定的伤残等级享受

## 数字与阈值
- 停工留薪期：一般不超过12个月，可延长不超过12个月（第33条）
- 生活护理费：50% / 40% / 30%（第34条）
- 一次性伤残补助金：一级27、二级25、三级23、四级21、五级18、六级16、七级13、八级11、九级9、十级7（个月本人工资，第35–37条）
- 伤残津贴：一级90%、二级85%、三级80%、四级75%、五级70%、六级60%（第35–36条）
- 丧葬补助金：6个月统筹地区上年度职工月平均工资（第39条）
- 供养亲属抚恤金：配偶40%、其他亲属30%、孤寡老人/孤儿+10%，总和不高于生前工资（第39条）
- 一次性工亡补助金：上一年度全国城镇居民人均可支配收入的20倍（第39条）
- 下落不明：3个月内照发工资，第4个月起停发；可预支工亡补助金50%（第41条）
