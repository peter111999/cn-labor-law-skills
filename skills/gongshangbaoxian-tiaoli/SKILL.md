## 适用情形

用户出现以下说法时，优先调用本技能：
- "算不算工伤""上班路上出车祸""工作时受伤" → 第三章（第14条）
- "突发疾病48小时内死亡""见义勇为受伤" → 第15条（视同工伤）
- "工伤认定谁来申请""申请时限多久" → 第17条（单位30日、职工或近亲属1年）
- "工伤认定要多少天" → 第20条（60日；事实清楚的15日）
- "伤残等级怎么划分" → 第四章（第22条，十个伤残等级）
- "不服鉴定结论怎么办" → 第26条（15日内申请再次鉴定）
- "停工留薪期工资怎么发" → 第33条（原工资福利不变，一般不超过12个月）
- "一次性伤残补助金几个月工资" → 第35–37条（27/25/23/21、18/16、13/11/9/7个月）
- "工亡赔偿有哪些" → 第39条（丧葬补助金、供养亲属抚恤金、一次性工亡补助金）
- "公司没交工伤保险怎么办" → 第62条（责令补缴、滞纳金、罚款；费用由单位支付）
- "工伤认定申请要交什么材料""单位不给报工伤怎么办" → ch09《工伤认定办法》第4–8条（单位30日、职工1年、申请材料清单、15日审核）
- "工伤认定决定多久下来""不服认定结果怎么办" → ch09《工伤认定办法》第18条（60日）、第21条（事实清楚15日）、第23条（行政复议或行政诉讼）
- "单位不承认是工伤谁举证" → ch09《工伤认定办法》第17条（用人单位举证责任）
- "几级伤残怎么定""这个伤算几级" → ch10（GB/T 16180—2014，国家标准，一级至十级定级原则与条款系列；仅作伤残等级判定参考）
- "伤残等级鉴定的原则是什么" → ch10（GB/T 16180—2014 第4章总则：综合判定、晋级原则等）
