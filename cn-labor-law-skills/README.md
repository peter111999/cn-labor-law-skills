# 适用于大陆地区劳动争议案件相关的 Agent Skills

> 把现行劳动法律法规与官方典型案例，蒸馏成 AI 可快速定位条文的 skill。

每个 skill 对应一部法规、一批案例或一个功能主题：层级索引 + 条文/案例原文 + 适用情形说明。AI 回答相关问题时调用对应 skill，**回答首行固定输出标识** `【📜 <中文名> · <slug>】`，一眼可验证调用成功。

## 安装使用

1. 克隆本仓库。
2. 将 `skills/<目录名>` 复制到你的 AI 助手的 skills 目录（Claude Code 示例：`~/.claude/skills/` 或项目内 `.claude/skills/`）。
3. 直接提问，AI 会按问题自动调用相关 skill；回答首行的 `【📜 …】` 标识即调用成功的证明。

## 数据来源与质量承诺

- 法规与案例原文来自官方发布文本（全国人大、国务院、人社部、最高人民法院官网），已**逐字核对**，严禁虚构。
- 条文号、款项、日期、数字阈值全部回源核实；款项不能确认时只引用到条，不补猜。
- 法律、行政法规、部门规章、司法解释、规范性文件、国家标准、典型案例**严格区分性质**，不混同。
- 典型案例为官方"典型案例"（**不是指导性案例**），原文逐字收录。
- 地方口径不一致处（如加班费计算基数）单独标注，并提示咨询当地仲裁委或律师。
- 法律法规可能修订：使用时请以官方最新公布为准（例：解释（一）第 32 条第 1 款已于 2025-09-01 被解释（二）第 21 条废止）。
