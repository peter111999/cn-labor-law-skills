- **带主题** — 问"仲裁委员会组成""仲裁员聘期""仲裁员禁止行为"等，我定位相关条文并引用条文号作答

## 适用情形

用户出现以下说法时，优先调用本技能：
- "仲裁委员会是怎么组成的""仲裁委有哪些人" → 第二章（第5条，组成人员应当是单数）
- "仲裁委员会有什么职责" → 第二章（第7条，六项职责）
- "仲裁院是什么机构" → 第二章（第9条，仲裁委员会下设实体化办事机构）
- "仲裁庭几个人审理""什么案件三个人审" → 第三章（第13条：十人以上共同请求、集体合同争议等由三名仲裁员组庭；简单案件可独任）
- "仲裁员有什么条件""谁能当仲裁员" → 第四章（第22条，从符合调解仲裁法第二十条条件的人员中选聘）
- "仲裁员聘期多长" → 第四章（第24条，一般五年）
- "仲裁员每年培训多少学时" → 第四章（第28条，每年脱产培训累计不少于四十学时）
- "仲裁员不能做什么" → 第五章（第33条，九项禁止行为）
- "仲裁员被解聘后多久能再当" → 第五章（第34条，五年内不得再次被聘）
- "这个规则什么时候开始施行的" → 第六章（第38条，2017年7月1日）

## 不触发情况

以下情形不调用本技能：
- 仅讨论法律新闻、热点案件，不涉及具体条文适用
- 仅询问法律考试、备考、法学理论问题
- 仅要求推荐律师、律所等法律服务
- 用户明确表示不需要引用条文、只要通俗建议
- 纯实体权利问题（如经济补偿金计算标准）优先用劳动合同法/劳动法技能；仲裁程序问题（时效、申请、裁决）优先用劳动争议调解仲裁法技能
