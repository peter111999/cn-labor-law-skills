# 第五阶段：二审 ⭐重点（stages/s05）

## 期限（关键）

| 事项 | 期限 | 出处 |
|---|---|---|
| 上诉期（判决） | 判决书送达之日起 **15 日内** | 《中华人民共和国民事诉讼法》第171条 |
| 上诉期（裁定） | 裁定书送达之日起 **10 日内** | 同上 |
| 原审法院送达上诉状副本 | 收到上诉状之日起 **5 日内**送达对方 | 《中华人民共和国民事诉讼法》第174条 |
| 对方提交答辩状 | 收到上诉状副本之日起 **15 日内** | 同上 |
| 原审法院报送案卷 | 收到上诉状、答辩状之日起 **5 日内**连同全部案卷证据报送二审法院 | 同上 |
| 二审审限（判决上诉） | 二审立案之日起 **3 个月内**审结；特殊情况需延长由本院院长批准 | 《中华人民共和国民事诉讼法》第183条 |
| 二审审限（裁定上诉） | 二审立案之日起 **30 日内**作出终审裁定 | 同上 |

## 上诉状要点

- 写明上诉人/被上诉人信息、**上诉请求**（撤销/改判的具体内容）、事实与理由
- 上诉请求要**具体明确**：二审审查范围是"上诉请求的有关事实和适用法律"（《中华人民共和国民事诉讼法》第175条）——没提的上诉请求，二审一般不审
- 针对一审的**事实认定错误**和**法律适用错误**分别论述，附证据页码索引

## 二审审理特点

- 二审法院对上诉案件**应当开庭审理**；经阅卷、调查和询问当事人，对没有提出新事实、证据或理由、法院认为不需要开庭的，**可以不开庭审理**（《中华人民共和国民事诉讼法》第176条）——实务中二审不开庭书面审理的情形不少，要有书面审理的准备
- 除本章（二审程序）规定外，**适用第一审普通程序**（《中华人民共和国民事诉讼法》第181条）
- 二审判决宣告前，上诉人可申请**撤回上诉**，是否准许由二审法院裁定（《中华人民共和国民事诉讼法》第180条）

## 二审四种裁判结果

《中华人民共和国民事诉讼法》第177条：

1. 原判决认定事实清楚、适用法律正确的 → **驳回上诉，维持原判**
2. 原判决认定事实错误或适用法律错误的 → **依法改判、撤销或变更**
3. 原判决认定基本事实不清的 → **撤销原判，发回重审**，或查清事实后改判
4. 原判决遗漏当事人或违法缺席判决等严重违反法定程序的 → **撤销原判，发回重审**

注意：发回重审的案件作出判决后，当事人**再次上诉的，二审法院不得再次发回重审**。

## 二审准备清单

- [ ] 一审判决书逐段批注：事实认定、证据采信、法律适用各有什么问题
- [ ] 上诉状：上诉请求逐项对应一审判项
- [ ] 新证据：二审中提交新证据的，说明逾期提交的理由（一审举证期限规则仍可参照）
- [ ] 答辩准备：如果对方上诉，15 日内提交答辩状（《中华人民共和国民事诉讼法》第174条），不提交不影响审理但建议提交
- [ ] 二审开庭/询问提纲：围绕上诉请求组织，每项请求对应证据

## 风险点

- ⚠️ **上诉期是硬伤**：15 日/10 日从送达之日起算，超期未上诉一审判决生效，没有补救
- ⚠️ **二审审查限于上诉请求**（《中华人民共和国民事诉讼法》第175条）：只有对方上诉、你没上诉时，你未提异议的一审判项二审一般不主动审查；但对方上诉请求指向的判项可能被改判，改判方向不确定。所以收到一审判决后，即使对方已上诉，也要评估自己是否需要在上诉期内提起上诉——超期就丧失了机会
- ⚠️ **发回重审≠胜诉**：发回只是程序性处理，重审结果未定
- ⚠️ 二审可能不开庭：书面审理时，上诉状和答辩状的质量决定一切，文字功夫要做足
