# 术语表

> 定义均出自《关于确立劳动关系有关事项的通知》（劳社部发〔2005〕12号）原文，不作引申。

| 术语 | 原文含义 |
|---|---|
| 劳动关系 | 用人单位招用劳动者未订立书面劳动合同、但同时具备第一条（一）（二）（三）项情形的，劳动关系成立 |
| 主体资格 | 用人单位和劳动者符合法律、法规规定的主体资格（第一条第（一）项） |
| 劳动规章制度 | 用人单位依法制定的各项劳动规章制度；适用于劳动者是劳动关系成立的情形之一（第一条第（二）项） |
| 劳动管理 | 劳动者受用人单位的劳动管理（第一条第（二）项） |
| 有报酬的劳动 | 劳动者从事用人单位安排的有报酬的劳动（第一条第（二）项） |
| 用人单位业务的组成部分 | 劳动者提供的劳动是用人单位业务的组成部分（第一条第（三）项） |
| 工资支付凭证或记录 | 包括职工工资发放花名册；缴纳各项社会保险费的记录亦属此类凭证（第二条第（一）项） |
| 招用记录 | 劳动者填写的用人单位招工招聘"登记表""报名表"等（第二条第（三）项） |
| 举证责任 | 第二条第（一）、（三）、（四）项的有关凭证，由用人单位负举证责任 |
| 无固定期限劳动合同 | 符合签订无固定期限劳动合同条件的劳动者提出订立时，用人单位应当订立（第三条） |
| 用工主体资格 | 具备依法用工的主体资格；建筑施工、矿山企业等将工程（业务）或经营权发包给不具备用工主体资格的组织或自然人时，由具备用工主体资格的发包方承担用工主体责任（第四条） |
| 用工主体责任 | 第四条规定的情形下，由具备用工主体资格的发包方承担的责任 |
| 劳动争议仲裁委员会 | 劳动关系争议可向有管辖权的劳动争议仲裁委员会申请仲裁（第五条） |
