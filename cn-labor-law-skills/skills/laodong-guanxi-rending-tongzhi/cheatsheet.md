# 核心规则速查

> 全部回原文核实，带条目序号。

## 劳动关系成立三要素（第一条）

同时具备下列情形，劳动关系成立：
1. 用人单位和劳动者符合法律、法规规定的**主体资格**
2. 用人单位依法制定的各项劳动规章制度**适用于劳动者**，劳动者受用人单位的**劳动管理**，从事用人单位安排的**有报酬的劳动**
3. 劳动者提供的劳动是**用人单位业务的组成部分**

## 认定凭证与举证责任（第二条）

- 五项参照凭证：工资支付凭证或记录（职工工资发放花名册）、社保缴费记录 / 工作证、服务证等身份证明证件 / 招工招聘登记表、报名表等招用记录 / 考勤记录 / 其他劳动者证言
- **其中第（一）（三）（四）项的有关凭证由用人单位负举证责任**（即工资支付凭证或记录、招用记录、考勤记录的有关凭证）

## 补签与终止（第三条）

- 符合第一条情形 → 用人单位应当与劳动者**补签劳动合同**，期限协商确定
- 协商不一致 → 任何一方均可提出**终止**劳动关系
- 符合签订无固定期限劳动合同条件、且劳动者提出的 → 用人单位**应当订立**
- **用人单位提出终止** → 按工作年限**每满一年支付一个月工资的经济补偿金**

## 发包方用工主体责任（第四条）

- 建筑施工、矿山企业等用人单位，将工程（业务）或经营权**发包给不具备用工主体资格的组织或自然人**
- 对该组织或自然人招用的劳动者 → **由具备用工主体资格的发包方承担用工主体责任**

## 争议解决（第五条）

- 劳动关系争议 → 向**有管辖权的劳动争议仲裁委员会申请仲裁**
