# 关键条文速查（全部回源核实，带条文号）

## 数字阈值

| 内容 | 阈值 | 条文 |
|---|---|---|
| 二倍工资计算 | 按月计算；不满一个月的，按该月实际工作日计算 | 第6条 |
| 协商延长劳动合同期限累计 | 达到1年以上，届满的，认定为连续订立二次固定期限劳动合同 | 第10条第1项 |
| 合同期满后继续用工 | 超过1个月未表示异议，劳动者可请求以原条件续订劳动合同 | 第11条 |
| 施行日期 | 2025年9月1日起施行 | 第21条 |

## 高频指引

| 问题 | 答案要点 | 条文 |
|---|---|---|
| 包工头没资质，找谁要工资和工伤待遇 | 可请求确认有资质的承包人为用工主体责任单位 | 第1条 |
| 挂靠公司干活，找谁负责 | 可请求确认被挂靠单位为用工主体责任单位 | 第2条 |
| 被几个关联公司来回用工 | 有书面合同按合同确认；无合同看用工管理行为综合认定；关联单位可共同承担报酬福利责任 | 第3条 |
| 公司没签合同，二倍工资怎么算 | 按月计算；不满一月按实际工作日算 | 第6条 |
| 劳动者自己故意不签合同，还能要二倍工资吗 | 不能（用人单位举证证明劳动者故意或重大过失未订立的除外） | 第7条第2项 |
| 合同到期公司一直不续签也不表态，超过一个月了 | 可请求以原条件续订；符合无固定期限情形的可请求订立无固定期限合同 | 第11条 |
| 公司给了特殊待遇（落户/住房等）约定服务期，我提前走了 | 公司可请求赔偿损失，法院按实际损失、过错程度、已履行年限等因素确定 | 第12条 |
| 没接触过公司机密，竞业限制协议有效吗 | 无效，劳动者可请求确认不生效 | 第13条第1款 |
| 竞业限制范围定得太大 | 超过合理比例部分无效 | 第13条第2款 |
| 在职期间的竞业限制约定有效吗 | 有效；不得以未支付经济补偿为由主张无效 | 第14条 |
| 违反竞业限制要赔多少 | 返还已支付的经济补偿 + 按约定支付违约金 | 第15条 |
| 公司违法解除，什么情况下算"不能继续履行" | 6种情形（合同期满无续订续延情形、享受养老保险待遇、破产、解散、已入职他处等） | 第16条 |
| 公司说好不交社保，每月多发钱，可以吗 | 约定无效；劳动者可依劳动合同法38条解约并要经济补偿 | 第19条 |
| 仲裁时没提时效抗辩，一审还能提吗 | 不能（有新证据证明时效届满的除外） | 第20条 |
| 解释二和解释一冲突听谁的 | 以解释二为准；解释一第32条第1款同时废止 | 第21条 |
