# 术语表（仅收录解释正文中出现的术语，定义忠实原文）

| 术语 | 出处 | 说明 |
|---|---|---|
| 用工主体责任 | 第1–2条 | 转包、分包、挂靠情形下，承包人/被挂靠单位承担支付劳动报酬、认定工伤后的工伤保险待遇等责任 |
| 关联单位 | 第3条 | 存在关联关系的多个单位；劳动者被交替或同时用工时，按情形确认劳动关系 |
| 混同用工 | 第3条（新闻背景） | 劳动者被多个关联单位交替或同时用工的情形 |
| 二倍工资 | 第6–7条 | 未依法订立书面劳动合同应支付的二倍工资；按月计算，不满一月按实际工作日计算 |
| 自动续延 | 第8条 | 合同期满因法定情形（不得解除情形/服务期未到期/工会任期未届满）期限依法自动续延 |
| 连续订立二次固定期限劳动合同 | 第10条 | 符合劳动合同法第14条第2款第3项的四种认定情形 |
| 特殊待遇 | 第12条 | 除正常劳动报酬外用人单位向劳动者提供的特殊待遇；约定服务期+特殊待遇后劳动者违约的，按损失赔偿规则处理 |
| 竞业限制 | 第13–15条 | 劳动者未知悉接触商业秘密和知识产权保密事项的，条款不生效；超出合理比例部分无效；在职期间约定有效；违反的返还经济补偿并支付违约金 |
| 商业秘密和与知识产权相关的保密事项 | 第13–14条 | 判断竞业限制条款效力与合理比例的基准 |
| 不能继续履行 | 第16条 | 违法解除后认定为劳动合同法第48条"劳动合同已经不能继续履行"的六种情形 |
| 职业健康检查 | 第17条 | 从事接触职业病危害作业劳动者的离岗前职业健康检查 |
| 仲裁时效抗辩 | 第20条 | 须在仲裁期间提出；仲裁期间因自身原因未提出，一审/二审/再审再提的不予支持 |
