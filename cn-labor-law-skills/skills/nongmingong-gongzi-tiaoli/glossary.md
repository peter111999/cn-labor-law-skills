# 术语表

本表只收录《保障农民工工资支付条例》原文中出现的术语，定义均出自原文。

| 术语 | 定义（出自原文） |
|---|---|
| 农民工 | 为用人单位提供劳动的农村居民（第2条） |
| 工资 | 农民工为用人单位提供劳动后应当获得的劳动报酬（第2条） |
| 劳动用工实名制管理 | 用人单位与招用的农民工书面约定或通过依法制定的规章制度规定工资支付标准、支付时间、支付方式等内容（第6条）；工程建设领域指订立劳动合同并进行用工实名登记，未登记人员不得进入项目现场施工（第28条） |
| 工资支付台账 | 用人单位按工资支付周期编制的书面台账，至少保存3年，包括用人单位名称、支付周期、支付日期、支付对象信息、工作时间、应发/代扣/实发工资等内容（第15条） |
| 工资清单 | 用人单位向农民工支付工资时，应当提供给农民工本人的工资清单（第15条） |
| 清偿 | 用人单位拖欠农民工工资后依法予以清偿的责任（第16条） |
| 追偿 | 用工单位、施工总承包单位等先行清偿后，依法向实际责任主体追回款项（第18条、第19条、第30条） |
| 垫付 | 建设单位以未结清的工程款为限先行垫付被拖欠的农民工工资（第29条）；县级以上地方政府动用应急周转金先行垫付（第63条） |
| 人工费用 | 工程施工合同中按保障农民工工资按时足额支付要求约定的费用，拨付周期不得超过1个月（第24条） |
| 工程款支付担保 | 建设单位应当向施工单位提供的担保（第24条） |
| 农民工工资专用账户 | 施工总承包单位开设的、专项用于支付该工程建设项目农民工工资的账户（第26条） |
| 劳资专管员 | 施工总承包单位在工程项目部配备的、对分包单位劳动用工实施监督管理的人员（第28条） |
| 用工管理台账 | 施工总承包单位、分包单位建立的台账，保存至工程完工且工资全部结清后至少3年（第28条） |
| 工资保证金 | 施工总承包单位按规定存储的、专项用于支付被拖欠工资的资金，可用金融机构保函替代，实行差异化存储（第32条） |
| 维权信息告示牌 | 施工总承包单位在施工现场醒目位置设立的告示牌，明示各方基本信息、最低工资标准、投诉举报电话等（第34条） |
| 失信联合惩戒对象名单 | 用人单位拖欠农民工工资情节严重或造成严重不良社会影响时，有关部门将其及相关责任人列入的名单，在多领域依法依规予以限制（第48条） |
| 应急周转金 | 县级以上地方政府在用人单位一时难以支付或逃匿时动用、先行垫付部分工资或基本生活费的资金，垫付后向用人单位追偿（第63条） |
| 拒不支付劳动报酬罪 | 人社部门发现欠薪违法行为涉嫌构成该罪的，及时移送公安机关审查（第41条） |
